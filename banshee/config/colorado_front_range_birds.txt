# Colorado Front Range / Jefferson County species allowlist
# -----------------------------------------------------------
# Curated for feeder + yard cameras around Evergreen, CO (~7200 ft,
# montane conifer-oak belt). Biased toward species that plausibly
# appear in a feeder frame, forest-canopy frame, or as a flyover;
# deliberately excludes open-plains specialists, shorebirds, and
# waterfowl that are unlikely in this habitat.
#
# Format: one Latin binomial per line. Comments start with "#".
# The loader only reads the first two whitespace-separated tokens,
# so adding the common name in parens is fine.
#
# The iNat 965-class model this maps into uses older taxonomy in
# some families (e.g. Picoides, not Dryobates, for Downy/Hairy
# Woodpeckers; Oreothlypis, not Leiothlypis, for Orange-crowned).
# The entries below match the labels file shipped on Thoth — do
# not "modernize" the genus without also updating the model.
#
# Ownership: edit freely. The allowlist is a pragmatic geography
# filter, not an authoritative checklist — if a real rarity shows
# up and gets filtered out, add it and move on.
